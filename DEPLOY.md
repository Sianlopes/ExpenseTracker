## Vercel + Render Setup

Frontend:
- Host the Vite app on Vercel.
- Set `VITE_API_BASE_URL` in Vercel to your Render backend URL, for example `https://expense-tracker.onrender.com`.

Backend:
- Host the Express server on Render using `render.yaml`.
- Set `MONGODB_URI` in Render.
- `CLIENT_URL` is already set to `https://expense-tracker-6i63.vercel.app`.
- `SESSION_SECRET` is generated by Render.

Check:
- Backend health URL: `/api/health`
- Frontend will call the backend URL from `VITE_API_BASE_URL`.
